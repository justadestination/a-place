# Session List Component

Task 4.3: Session management.

Displays active devices and sessions for a user, highlighting the current device with a badge, allowing single-click revocation of individual remote devices or global sign-out of all other devices.

## Features
- Accessible WCAG 2.2 AA markup with zero Axe violations.
- Live ARIA announcements (`role="status"`, `aria-live="polite"`).
- Touch targets strictly conforming to `--nc-size-target` (≥44px).
- Strict design token discipline (zero raw hex or px).
