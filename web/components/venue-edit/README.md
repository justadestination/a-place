# Venue quick-edit

A short form for the person who runs a venue, or for an operator.

- Save the venue name and address.
- Add a show with a title, date, and start time.
- Publish a news blurb. It appears on this page immediately and on the venue page.

Open `/edit/?id=<venue id>` or `/embed/venue-edit/?id=<venue id>&session=<token>&zkp=<token>`.
