# Entity page

A page for one promoter, band, comedian, or other entity.

- Profile, contact, linked events, and linked zine articles.
- Event rows link to the venue, and each known performer links back to `/entity/?id=&type=`.
- A zine article whose title names an entity links to that entity page.

Open `/entity/?id=ent_band_wave&type=band` or `/embed/entity-page/?type=band&id=ent_band_wave`.
