# Zine Print Marker Component

Visual marker card embedding scannable QR data with editorial styling and printed URL fallbacks (Task 3.8).

## Purpose
Renders an editorial preview of physical print markers designed for Umwelt Horizons zine pages.

## Features
- **Editorial QR**: Level H error-correction SVG matrix designed into the page styling.
- **Printed URL Fallback**: Displays the mandatory accompanying human-readable URL fallback (`shady.example.org/portal/?target=...`).
- **Interactive Portal Link**: Provides direct navigation to the digital portal destination.
- **Accessible & Token-compliant**: Uses semantic elements and strict design tokens.
