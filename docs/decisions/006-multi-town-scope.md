# Decision 006: Multi-Town Scope & Target Geography

- **Date:** 2026-10-08
- **Decider:** the operator
- **Status:** Approved

## Decision

1. **Target Scope:**
   - **Santa Rosa only** for this test build.
   - Initial geography, coordinates, venue profiles, map boundaries, and default calendar seeds are focused exclusively on Santa Rosa, CA.

2. **Roadmap Separation:**
   - Dynamic multi-town support, municipal zoning switching, and multi-town node federation are explicitly deferred to post-test roadmap phases.

3. **Public Deployment:**
   - The test build will be deployed publicly at `https://shady.example.org`.
